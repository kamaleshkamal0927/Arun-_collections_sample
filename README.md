# ARUN COLLECTIONS — Digital Showroom & Heritage Website

> **"Adding Values to Lives."**  
> Physical Showroom: 94/3, Adam Street, Alamelu Manga Puram, Sankarapuram, Mylapore, Chennai, Tamil Nadu, India.

A premium, mobile-first, 3-page digital showroom built with **Next.js (App Router)**, **TypeScript**, and **Tailwind CSS**. It captures the sacred heritage of historic Mylapore with antique brass aesthetics, warm ivory tones, and the divine presence of the **Sacred Murugan Vel (ஞானவேல்)**.

---

## 🔱 Key Features & Architecture

- **Clean 3-Page Structure (Zero Clutter, Zero E-Commerce)**:
  1. **Home (`/`)**: Brand identity, authentic story of antique preservation, curated category highlights, 6 verified pillars, 12.2K Instagram showcase, and 4.6★ Google reviews.
  2. **The Collection (`/collections`)**: Digital showroom gallery with category filter pills, authentic minimalist captions, and a Collector's Lightbox with pre-filled WhatsApp inquiry.
  3. **Visit & Contact (`/visit`)**: Verified Mylapore store coordinates, interactive Google Maps embed, one-click copy address, and direct one-tap Call/WhatsApp/Directions buttons.
- **Sacred Murugan Vel & Positive Divine Energy**:
  - Handcrafted SVG vector of the sacred Murugan Vel with golden gradient, authentic leaf-spear blade, central nerve, holy Vibhuti (three white stripes), and Kumkum tilak.
  - Ambient radiant aura giving a serene, positive divine vibration (ஓம் • வெற்றிவேல் • சுபமஸ்து).
- **Mylapore Antique Theme**:
  - Warm parchment / ivory backgrounds (`#FAF7F2`)
  - Deep heritage espresso / charcoal typography (`#1E1712`)
  - Muted antique gold & temple brass accents (`#C69C4B`, `#A87932`)
  - Refined serif headings paired with clean modern body typography.
- **Mobile-First Experience**:
  - Fixed mobile bottom navigation bar for instant Call, WhatsApp, Directions, and Instagram access.
- **Local SEO & Schema.org**:
  - Semantic HTML5, dynamic `sitemap.xml` and `robots.txt`.
  - JSON-LD `AntiqueStore` / `LocalBusiness` schema for Mylapore, Chennai search discovery.

## 🚀 Getting Started

### 1. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 2. Production Build & Start
```bash
npm run build
npm run start
```
